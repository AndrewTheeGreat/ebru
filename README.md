# Ebru: a marbling bath

A digital paper-marbling bath in one self-contained HTML file. Float ink on water, comb it into traditional Ottoman and Japanese patterns, then pull a mirrored paper print and hang it up to dry.

**Run it:** open `ebru.html` in a browser. There is no build step.

- Tools: Drop, Sprinkle, Stylus, Comb, Swirl (keys 1–5)
- 8 recipes: Battal, Gelgit, Taraklı, Feather, Hatip, Lale, Suminagashi, Girdap
- Shortcuts: `Q` palette · `Z` undo · `P` print · `Backspace` skim · `M` sound · `?` help

Ink regions are vector polygons moved by closed-form marbling transforms (in the style of Jaffer & Lu), so patterns stay crisp. All sound is synthesized with WebAudio.

The brainstorm and build plan are in `notes/`.
